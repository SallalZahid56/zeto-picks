# Zeto Picks 🏀🎯

## Project Overview

**Zeto Picks** is a modern, responsive landing page for a premium sports betting community dedicated to **Player Props** betting. The platform brings together 20,000+ members who share betting picks and strategies across major sports leagues including NBA, NFL, MLB, and NHL.

The mission is simple: **Stop Guessing. Start Cashing.** — Zeto has built a thriving community with an impressive **81% win rate**, helping members make informed betting decisions and maximize their returns.

---

## Key Features ✨

- **Responsive Design**: Fully mobile-optimized with a responsive navbar and hamburger menu
- **Modern UI/UX**: Clean, professional interface with gradient backgrounds and smooth animations
- **Community Showcase**: Highlights community statistics and social proof
- **Member Access**: Call-to-action sections throughout for joining the community
- **Sports Coverage**: Betting picks across NBA, NFL, MLB, and NHL
- **Smooth Navigation**: Anchor-link navigation for seamless scrolling between sections

---

## Sections Included 📋

1. **Navbar** - Fixed navigation with logo, menu links, and mobile hamburger
2. **Hero Section** - Eye-catching introduction with key statistics and value proposition
3. **Who Is Zeto** - Background and credibility section
4. **Results** - Community performance and win statistics
5. **Community** - Member testimonials and social proof
6. **Pricing** - Membership tiers and call-to-action

## Technologies & Stack 🛠️

### Frontend Frameworks & Libraries
- **HTML5** - Semantic markup and structure
- **CSS3** - Custom styling with animations and transitions (Zeto.css)
- **Tailwind CSS** - Utility-first CSS framework via CDN for rapid development
- **JavaScript** - Vanilla JS for interactive elements (navbar, mobile menu)

### Design & Typography
- **Bebas Neue Font** - Bold, modern heading font for branding
- **Barlow Font** - Clean, readable sans-serif for body text
- **CSS Gradients** - Beautiful gradient backgrounds and effects
- **Backdrop Filters** - Glassmorphism effects on navbar

### Key Design Patterns
- **Responsive Grid Layout** - Mobile-first approach with Tailwind breakpoints
- **CSS Animations** - Smooth transitions and hover effects
- **Blob Decorations** - Organic background shapes for visual interest
- **CSS Variables** - Centralized color management (orange accent: `#F35525`)

## Customization Guide 🎨

### Change Brand Colors
Edit the CSS variable in `Zeto.css`:
```css
:root {
  --orange: rgb(243, 85, 37); /* Change this value */
}
```

### Modify Navigation Links
Update the links in the navbar or mobile menu sections in `index.html`:
```html
<li><a href="#your-section" class="nav-link">Your Link</a></li>
```

### Update Statistics
Modify the numbers in the hero stats section:
```html
<span class="stat-num">YOUR_NUMBER</span>
```
